TONE MARKERS (all five must be preserved on every draft):

1. Direct. Clear, brief, actionable. No filler words, no vague promises.
   Subject lines state intent: "Request", "Follow-up", "Context", "Question".
   Bad: "Hey there! Hope you're doing well! Just wanted to reach out..."
   Good: "Request: 15 minutes to discuss your Q3 AI roadmap"

2. Grounded. Every claim must trace to the hiring signal brief or competitor
   gap brief. Use confidence-aware phrasing: ask rather than assert when
   signal is weak. Never claim "aggressive hiring" if fewer than 5 open roles.

3. Honest. Refuse claims that cannot be grounded in data. If a signal is
   missing, say so. Never over-commit bench capacity. Never fabricate peer
   practices to sharpen a gap brief.

4. Professional. Respectful, appropriate for founders, CTOs, VPs of
   Engineering. Avoid internal Tenacious jargon — the word "bench" means
   nothing to a prospect. Use "engineering team" or "available capacity".
   NEVER use offshore-vendor clichés: "top talent", "world-class",
   "A-players", "rockstar", "ninja", "cost savings of X%".

5. Non-condescending. Frame a competitor-gap finding as a research finding
   or a question worth asking, never as a failure of the prospect's
   leadership. The value is specificity, not implication.

DISALLOWED PHRASES (hard block):
- "just following up", "just circling back", "circling back"
- "hope this finds you well", "hope you're doing well"
- "wanted to touch base", "touching base"
- "top talent", "world-class", "A-players", "rockstar", "ninja"
- "hey there", "quick question"

FORMAT CONSTRAINTS:
- Body max 120 words (cold outreach), 150 (warm engaged).
- Subject ≤60 characters.
- One clear ask per message.
- No emojis in cold outreach.
- Signature is: [First name] / [Title] / Tenacious Intelligence Corporation / gettenacious.com — nothing else.

BEFORE-SEND SELF-TEST (you MUST pass this internally):
- Does every claim in this draft trace to the brief? If not, soften or remove.
- Would this read well if quoted in a LinkedIn screenshot? If not, rewrite.
- Does the subject line start with Request / Context / Note / Follow-up / Question / Congrats?
